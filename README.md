# Maquettes du nouveau site — Ouvrir Les Yeux

Prototype navigable de la refonte du site de l'association Ouvrir Les Yeux (OLY).
Document de travail, non contractuel. Site publié avec GitHub Pages : la page d'entrée est `index.html`.

## Contenu

| Fichier | Page |
|---------|------|
| `index.html` | Sommaire des maquettes |
| `accueil.html` | Accueil |
| `actualites.html` | Liste Nos Actualités |
| `article.html` | Gabarit article / actualité |
| `page-a.html` / `page-b.html` | Gabarit page de contenu, variantes A et B |
| `don.html` | Faire un don |
| `systeme-de-design.html` | Système de design (référence équipe projet) |
| `a-venir.html` | Page d'attente pour les liens pas encore maquettés |

## Mettre à jour

1. Les maquettes de référence sont tenues dans le canevas Claude « Maquettes OLY ».
2. Demander la modification à Claude dans le projet OLY.
3. Claude modifie le canevas, régénère les pages avec `outils/export.py`, vérifie l'accessibilité, puis pousse sur ce dépôt.
4. GitHub Pages republie le site automatiquement en une à deux minutes.

## Accessibilité

Conçu pour le RGAA / WCAG 2.1 AA. Chaque version est contrôlée avec axe-core en 1440 px et 390 px avant publication.
