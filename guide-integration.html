Démarrer

Ce guide décrit chaque élément réutilisable de la maquette : couleurs, typographie, espacements, composants, comportements. Chaque composant montre un exemple réel, ses mesures, ses règles d'accessibilité, sa structure HTML et une piste d'intégration dans le thème enfant Gutenberg.

Jetons (JSON, format W3C)Jetons (variables CSS)Système de design visuel
  • Police : Atkinson Hyperlegible 400 et 700 (WOFF2, hébergée sur le site, font-display: swap). La charte prévoit Luciole pour les titres ; cette maquette utilise Atkinson Hyperlegible partout.
  • Base : fond #FAF8F7, texte #1E2B3A, 18 px, interligne 1,6, box-sizing: border-box partout.
  • Conteneur : .wrap = 1344 px max, marges latérales 48 px (20 px ≤ 760 px). Colonne de lecture .read = 820 px.
  • Unités : la maquette est en px ; à l'intégration, convertir tailles de texte et espacements en rem (base 16 px) pour respecter le zoom navigateur.
  • Figma : le fichier JSON suit le format W3C Design Tokens, lisible par le plugin Tokens Studio pour créer les variables et styles ; les pages en ligne peuvent être importées en calques avec un plugin d'import de page web (par exemple html.to.design).

Composants : Actions

Boutons

Action principale (corail, une seule par zone), action secondaire (contour bleu), action discrète (bleu doux : partage). Un lien qui change de page reste un <a> stylé en bouton ; un <button> ne sert qu'aux actions sur place.

Exemple

Faire un donVoir toutes nos actionsVoir l'agenda

Spécifications

  • Classes : .btn + .btn-primary | .btn-secondary | .btn-soft
  • Gabarit : pilule (rayon 999), hauteur min. 52 px, padding 12 × 28 px, gras 18 px, gap icône 10 px
  • Principal : fond #D93A39, texte #FFFFFF (4,55:1) ; survol #B92F2E
  • Secondaire : fond #FFFFFF, bordure 2 px et texte #0A5CB0 ; survol fond #E3F0FC, texte #08498C
  • Doux : fond #CFE5FA, texte #1E2B3A ; survol #A9D1F5
  • Mobile : les boutons des bandeaux passent en pleine largeur (grilles .agir-btns, .utils)

Accessibilité

  • Aucune flèche, aucun chevron, aucun soulignement (réservé aux liens).
  • Libellé explicite hors contexte : « Je fais un don sur HelloAsso », pas « Cliquez ici ».
  • Focus : contour 3 px #0A5CB0 décalé de 2 px (global :focus-visible).
  • Désactivé : à éviter ; si nécessaire, aria-disabled="true" et texte #5B6470 sur bordure #B8C0CA.

Utilisé dans : Accueil, Faire un don, Article

Intégration WordPress suggérée : core/button avec 3 variations de style (is-style-primary, -secondary, -soft)

Structure HTML : Boutons

<a href="/don" class="btn btn-primary">Faire un don</a>
<a href="/nos-actions" class="btn btn-secondary">Voir toutes nos actions</a>
<button type="button" class="btn btn-soft">Copier le lien</button>

Liens texte

Lien dans un paragraphe, ou lien d'appel sous une carte (« Lire la page »).

Exemple

Consultez les démarches pour obtenir une aide humaine sur notre page dédiée.

Lire la page (dans une carte cliquable)

Spécifications

  • Couleur : #0A5CB0 (6,3:1 sur le fond) ; survol #08498C
  • Soulignement : toujours visible, épaisseur 2 px, décalage 3 px
  • .ulink : même rendu en gras, pour le faux lien visible dans une carte entièrement cliquable

Accessibilité

  • Jamais « cliquez ici », « en savoir plus » ou « ici » seuls.
  • Lien externe : le dire dans l'intitulé ou le texte qui suit (ex. « (site mdph.fr) »).
  • Un seul lien par carte : le <a> englobe la carte, .ulink n'est qu'un repère visuel.

Utilisé dans : Les démarches, Nos Actions

Intégration WordPress suggérée : styles globaux de theme.json (elements.link)

Structure HTML : Liens texte

<a href="/les-demarches">les démarches pour obtenir une aide humaine</a>
<span class="ulink">Lire la page</span>  <!-- dans une carte dont le <a> englobe tout -->

Composants : Navigation

En-tête et accès rapides

En haut de toutes les pages : logo (lien vers l'accueil), lien d'évitement, recherche, langues, bouton « Faire un don », puis menu principal.

Composant global : voir n'importe quelle page, par exemple Toutes les pages.

Spécifications

  • Hauteur : barre 96 px min. ; logo 64 px de haut (48 px sur mobile)
  • Fond : #FFFFFF ; filets #D9DEE5 au-dessus et au-dessous du menu
  • Langues : nom complet dans sa langue, langue active en gras couleur encre, séparateur « · » masqué
  • ≤ 1100 px : bouton « Menu » visible ; le lien d'évitement est masqué hors focus
  • ≤ 760 px : accès rapides sur toute la largeur, sous le logo ; « Faire un don » pleine largeur

Accessibilité

  • Le lien d'évitement est le premier élément focusable du vrai site (la barre de maquette n'existe pas en production).
  • lang et hreflang sur chaque langue ; pas de drapeau, pas d'abréviation.
  • Alternative du logo : « Ouvrir Les Yeux, pour voir demain : accueil ».

Utilisé dans : Toutes les pages

Intégration WordPress suggérée : partie de modèle header.html (template part) + bloc de navigation sur mesure

Menu principal à sous-menus

7 rubriques sur 2 lignes chacune, chacune avec sa couleur pastel et un sous-menu qui s'ouvre au clic (pas au survol).

Composant global : voir n'importe quelle page, par exemple Toutes les pages.

Spécifications

  • Grille : 7 colonnes égales ; séparateur vertical 2 px #767676 entre entrées
  • Entrée : hauteur 104 px, gras 18 px, centré ; fond = couleur de la rubrique ; ouverte ou active : fond #CFE5FA + trait bas 5 px #1E2B3A
  • Sous-menu : blanc, largeur 300 à 380 px, rayon bas 16 px, ombre « panel » ; liens 18 px, filet #E6E9ED ; survol fond #E3F0FC + soulignement ; les 2 derniers s'alignent à droite
  • ≤ 1100 px : liste verticale ; entrée 60 px de haut, texte à gauche, indicateur « + » / « − » à droite ; sous-menu en place, retrait 44 px

Accessibilité

  • Bouton avec aria-expanded et aria-controls ; un seul sous-menu ouvert à la fois.
  • Échap ferme le sous-menu et rend le focus à son bouton ; sur mobile, Échap ferme le menu et rend le focus à « Menu ».
  • Clic en dehors : ferme tout.
  • aria-current="page" sur le lien de la page en cours.
  • Rubriques séparées par une bordure ET une couleur, jamais la couleur seule.

Fil d'Ariane

Sur toutes les pages sauf l'accueil, en haut du bandeau de titre.

Exemple

  1. Accueil
  2. ›
  3. Les NOH
  4. ›
  5. Les traitements

Spécifications

  • Disposition : flex, retour à la ligne, gap 8 px
  • Dernier élément : gras, encre, non cliquable
  • Séparateur : « › » masqué aux lecteurs d'écran

Accessibilité

  • aria-current="page" sur le dernier élément.

Utilisé dans : Les traitements

Intégration WordPress suggérée : bloc d'un plugin de fil d'Ariane (Yoast, Rank Math) restylé, ou bloc sur mesure

Structure HTML : Fil d'Ariane

<nav aria-label="Fil d'Ariane">

    <li><a href="/">Accueil</a></li>
    <li aria-hidden="true">›</li>
    <li><a href="/les-noh">Les NOH</a></li>
    <li aria-hidden="true">›</li>
    <li><strong aria-current="page">Les traitements</strong></li>
  </ol>
</nav>

Filtres en onglets

Filtrer une liste (actualités : Toutes, Internes, Externes). Ce sont des liens, pas des onglets ARIA.

Exemple

  • Toutes
  • Internes
  • Externes

Spécifications

  • Onglet : pilule, hauteur 48 px, padding 8 × 22 px, bordure 2 px #0A5CB0, texte bleu gras ; survol fond #E3F0FC
  • Actif : fond #0A5CB0, texte blanc, coche ; survol #08498C

Accessibilité

  • L'état actif est porté par aria-current et une coche, pas seulement la couleur.
  • Annoncer le nombre de résultats sous les filtres.

Pagination

Listes longues (actualités).

Exemple

  • Page précédente
  • 1
  • 2
  • Page suivante

Spécifications

  • Numéro : cible 48 × 48 px, rayon 12 px, bleu gras ; page en cours fond #0A5CB0, texte blanc
  • Désactivé : texte #5B6470, bordure #B8C0CA, non cliquable
  • ≤ 760 px : numéros masqués (.pg-num), seuls « précédente / suivante » restent

Accessibilité

  • aria-current="page" sur la page en cours ; « Page précédente / suivante » en toutes lettres.

Comportements

  • Sous-menus : ouverture au clic sur le bouton (aria-expanded passe à true, le panneau perd hidden) ; un seul ouvert ; clic en dehors ou Échap pour fermer, Échap rend le focus au bouton ; l'entrée ouverte prend le fond #CFE5FA et le trait bas, l'indicateur passe de « + » à « − » (mobile).
  • Menu mobile (≤ 1100 px) : le bouton « Menu » bascule la classe is-open du menu, aria-expanded, son libellé (« Menu » / « Fermer le menu ») et son icône ; Échap le ferme et rend le focus au bouton.

Règles d'accessibilité communes

  • Contraste : 4,5:1 pour le texte courant, 3:1 pour les titres de 24 px et plus et pour les bordures de composants.

  • Repères : header, nav nommées (aria-label), main id="contenu", footer ; lien d'évitement en premier.
